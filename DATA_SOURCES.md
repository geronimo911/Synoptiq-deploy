# Data sources

Production forecasts are downloaded from NOAA GFS and ECMWF IFS/AIFS. Historical IFS/AIFS use official ECMWF Open Data mirrors (Azure, Google Cloud, ECMWF, AWS); MARS remains an explicit optional advanced mode, never an automatic fallback. The common training start is 2025-02-25. AIFS rows are tagged v1 before 2026-05-12 and v2 from that date. ECMWF Open Data GRIB `tp` may be reported in `kg m**-2` (numerically mm), so it is normalized to metres before cumulative differencing; the corrected AIFS bundle applies a guarded 0.001 conversion to legacy rows previously decoded as metres. The superseded `real_12m` model bundle used those unnormalized AIFS precipitation values and must not be deployed. Precipitation verification uses NASA GPM IMERG V07 Final (`GPM_3IMERGDF.07`); temperature and wind verification use ERA5 through Open-Meteo Historical Weather API with `models=era5`. NASA access uses Earthdata authentication; the account must authorize GES DISC at https://disc.gsfc.nasa.gov/earthdata-login. Provider outages or authorization failures are hard errors; the pipeline never fabricates replacement rows.

NASA Earthdata credentials are read from `NASA_EARTHDATA_USERNAME` and `NASA_EARTHDATA_PASSWORD` and used only for runtime authentication. ERA5 provenance records `source_dataset=ERA5`, the Open-Meteo Historical Weather API transport, and the ERA5 0.25 degree resolution. Raw GRIB/NetCDF belongs in configurable object storage or a raw cache, while processed ML data is Parquet.
